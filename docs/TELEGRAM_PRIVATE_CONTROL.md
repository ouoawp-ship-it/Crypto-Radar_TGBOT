# Telegram 管理员私聊菜单

管理员私聊菜单是独立、默认关闭的运维服务。它只接受 FinalShell 预先绑定的
管理员本人私聊；群消息、其他用户、机器人消息、转发消息和自由格式命令全部
忽略。该服务故障不会停止五个雷达。

## 私聊里可以做什么

主菜单按用途分成三类，直接点击带 Emoji 的按钮即可：

- 📊 **查运行**：雷达状态、系统健康、推送额度和话题状态；
- 📚 **查记录**：最近信号、推送记录、未推送原因和故障说明；
- 🎛️ **改开关**：五雷达开关，以及方向分析、按需 AI 解读和故障提醒；
- 🤖 **AI 设置**：配置密钥、HTTPS 接口、模型和补充提示词，并查看按钮、自动模式和每日额度的脱敏状态。

主菜单不再堆放全部开关按钮。“五雷达开关”和“功能开关”各自进入独立子菜单，
需要修改时仍必须完成第二次确认。

### 日常查看

- 查看五雷达状态、健康摘要、最近一小时发送额度和五个话题配置；
- 查看最近信号、最近推送记录和未推送原因；
- 查看固定中文故障说明，不回显原始异常；
- 查看方向雷达、AI 解读、主动故障提醒和五雷达主开关。

“未推送原因”只说明已经到达发送环节的记录，不能代替每个雷达内部完整的候选
淘汰历史。每页最多显示 8 条，只读本地文件和只读数据库，不调用市场接口。

### 安全开关

以下操作都需要在两分钟内发送精确的第二次确认：

- 开启或关闭方向雷达、按需 AI 白话解读；
- 开启或关闭主动故障提醒；
- 分别开启或关闭启动预警、资金摘要、资金费率警报、五因子资金流和公告风险。

五雷达主开关只控制自动调度，不会停止主进程、市场数据服务、公共市场快照、
清理和结果追踪，也不会修改真实推送模式。关闭期间不会补跑历史；重新开启后从
下一次正常调度继续。配置修改失败时保留旧配置。

### AI 解读设置

- 只有绑定管理员的私聊可以使用这个入口；密钥、接口和模型仍可选择在 FinalShell 配置；
- 雷达扫描默认不调用 AI。群内启动信号下方会出现“AI解读这条信号”，点击后跳到管理员私聊并按需分析；
- AI 使用该卡片发送时保存的白名单快照，不解析转发正文，也不会用后来行情改写当时结论；
- 相同快照、模型和提示词重复点击会复用缓存，不重复占用调用额度；默认每日最多 20 次真实请求；
- 私聊输入只在内存中交给配置管理器，不进入命令参数、私聊 offset、推送 History/Outbox、回复或日志；最终值只写入权限 600 的受保护配置及其备份；
- 保存成功后只显示“已配置”，不会回显原值；密钥消息会尽力自动删除，失败时会提示管理员手工删除；
- Telegram 本身会先处理私聊内容。密钥、接口和模型如需最高私密性，仍可改用 FinalShell；
- 补充提示词会发送给 AI 接口，禁止在其中填写密钥；它只能调整白话表达，不能覆盖方向、评分、失效位、输出格式或安全规则；
- 输入请求只在内存保留五分钟。服务重启后应重新进入 AI 设置；若密钥未被机器人消费，管理员必须手工删除该私聊消息。

## 主动故障提醒

默认关闭。开启后，每分钟只读检查主 BOT、五雷达、市场快照、实时行情和真实
推送小时额度。首次故障立即私聊提醒；同类持续故障默认一小时内不重复发送。
提醒只发给绑定管理员，不发生产群、不进入雷达话题，也不写业务推送历史。

```dotenv
TG_PRIVATE_CONTROL_ALERT_ENABLE=false
TG_PRIVATE_CONTROL_ALERT_COOLDOWN_SEC=3600
```

## FinalShell 继续保留什么

- 绑定或解除管理员；
- 设置 Telegram Token、群号；AI 配置仍可在这里作为更高私密性的备选；
- 切换真实发送、发送真实测试消息、修改真实发送确认；
- 创建、修复、删除话题或重新置顶；
- 安装、更新、部署、版本切换和整文件回滚；
- 启停服务、数据库备份恢复、完整日志和原始诊断。

一句话边界：Telegram 私聊负责日常查看、低风险开关和 AI 解读配置；FinalShell
负责身份、真实发送、服务、部署、日志和恢复，并保留 AI 配置的高私密性入口。

## 首次启用

在服务器运行 `paopao`，进入：

```text
Telegram 设置与测试
→ 管理员私聊菜单
```

先设置管理员 Telegram User ID，再选择“开启并启动私聊菜单”。所有输入在
FinalShell 明文显示，保存后的状态仍脱敏。服务名为
`paopao-private-control.service`；安装和更新只安装服务配置，默认不会自动启用。

基础配置：

```dotenv
TG_PRIVATE_CONTROL_ENABLE=false
TG_PRIVATE_CONTROL_ADMIN_USER_ID=
TG_BOT_USERNAME=
LAUNCH_AI_INTERPRETER_ENABLE=false
LAUNCH_AI_AUTO_ENABLE=false
AI_ON_DEMAND_DAILY_LIMIT=20
```

更换管理员时先停止并取消服务开机自启，写入成功后才按原状态恢复。私聊菜单
不能修改主 BOT 的真实发送模式或双重发送门禁，也不会显示 Token、用户号、
群号、话题号、API Key、接口地址、内部路径、消息编号或原始错误正文。
